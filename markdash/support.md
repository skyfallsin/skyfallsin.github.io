## Markdash support

Markdash is a fast, clean Markdown viewer for macOS. Open any `.md` file and
read it the way it was meant to look — headings, lists, links, images, and code,
all rendered. When you need to change something, double-click a block to edit
just that block; nothing else in the file is touched.

### Common questions

**How do I edit a file?**
Double-click any block to edit just that block. Press ⌘↩ to save, Esc to cancel.
Only the block you changed is written back — the rest of the file stays byte for
byte as it was.

**How do I see the raw Markdown?**
Press ⇧⌘R to show the raw Markdown next to a live preview.

**How do I make Markdash the default for `.md` files?**
Use the menu: Markdash › Make Markdash the Default for Markdown. macOS will ask
you to confirm.

**Does Markdash collect any data?**
No. Markdash does not collect, track, or transmit any of your data. Your files
stay on your Mac.

### Privacy

Markdash doesn't collect any data. It opens the files you choose and renders
them locally. Images referenced by a web URL are loaded from the web when a
document contains them; everything else stays on your machine. See the full
[privacy policy](/markdash/privacy/) for details.
